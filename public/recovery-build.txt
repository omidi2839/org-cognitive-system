ORG Cognitive System Document File & Amendment Stabilization
Version: 0.9.8.5
Deployment-safe; no new top-level API function.
- Article locator directives such as "ماده ۲۷ مصوبه ... به شرح ذیل..." are no longer treated as amendment body text.
- Actual substantive text after the locator is extracted and appended for a newly-created article.
- Edit form supports primary file replacement while keeping audit history.
- Edit form supports multiple new Word/PDF attachments.
- Registration form supports multiple Word/PDF attachments.
- Conditional edit fields mirror registration behavior: unit only for unit scope; end date only when not active.
- Primary normalized text remains isolated from attachment text in document view/structure.
