# Build 0.9.1.1 — Document Bank Visible Hotfix

این بسته به‌صورت مستقیم فایل‌های لازم را در مسیرهای اصلی پروژه جایگزین/اضافه می‌کند و برخلاف بسته قبلی نیازمند ویرایش دستی index.html نیست.

## فایل‌ها
- public/index.html — بارگذاری مستقیم قابلیت بانک اسناد
- public/document-bank-091.js — بانک اسناد، فارسی‌سازی اعداد و حذف برچسب Build
- public/document-bank-091.css — رابط بانک اسناد
- api/document-bank.js — جستجوی فراداده و متن استخراج‌شده
- vercel.json — مسیر اختصاصی API بانک اسناد قبل از catch-all

## قابلیت‌ها
- حذف نمایش Build 0.7.6.4
- فارسی‌سازی اعداد در فضای اسناد
- افزودن کارت/تب «بانک اسناد»
- جستجو در عنوان، موضوع، مرجع و متن نرمال‌شده سند
- فیلتر نوع سند، اعتبار، طبقه‌بندی، مرجع، موضوع و بازه تاریخ
- نمایش snippet محل تطابق متن
- هسته اولیه کنترل دامنه دسترسی در Backend

## محدودیت آگاهانه
اتصال دامنه‌های own/unit/subtree/organization به هویت، ساختار سازمانی و RBAC واقعی هنوز باید در Build امنیتی بعدی تکمیل شود. این Build هیچ امنیتی را صرفاً در Frontend شبیه‌سازی نمی‌کند.
